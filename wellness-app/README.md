# WellnessID（仮）

ウェルネス領域の**口コミアプリ**（iPhone向け）。
「悩みから探す → 比べる → 口コミを書く」を作ります。

> **アプリ名はまだ決まっていません。** `WellnessID` は仮の名前です。
> 名前が決まっても、変えるのは表示名だけで済むように作ってあります。

---

## 1. これは何のフォルダか

3つの部屋に分かれています。

| フォルダ | 何が入っているか | ひとことで言うと |
|---|---|---|
| `app/` | iPhoneアプリの中身 | **画面** |
| `functions/` | サーバー側の処理 | **計算と検査** |
| `firebase/` | データベースの設定 | **金庫の鍵** |

なぜ分けるのか。**「誰でも書き換えられたら困るもの」をアプリの外に出すため**です。
たとえば口コミの平均点をアプリ側で計算できてしまうと、点数を偽装できます。
そこで平均点の計算は `functions/` だけがやり、`firebase/` のルールで「アプリからは書けない」と決めています。

---

## 2. 特に大事な3つのファイル

この3つだけ覚えれば大丈夫です。

| ファイル | 役割 | さわるとき |
|---|---|---|
| `CLAUDE.md` | **ルールブック**。AIに実装させるときの決まりごと | 仕様が変わったとき |
| `app/src/types/` | **データの設計図**。どんな情報を持つか | 画面を作る前 |
| `app/src/theme/palette.js` | **色の一覧**。全部の色はここだけにある | 色を変えるとき |

## 3. 最初にやること

### ① 必要なものを入れる

VS Codeでターミナルを開き（`Ctrl` + `@`）、**`wellness-app` フォルダの中で**実行します。

**Windows（PowerShell）の場合**

```powershell
cd wellness-app
powershell -ExecutionPolicy Bypass -File scripts\bootstrap-app.ps1
```

**Mac / Linux / Git Bash の場合**

```bash
cd wellness-app
bash scripts/bootstrap-app.sh
```

5〜10分かかります。終わるまで待ってください。

> ⚠️ **OneDrive の中で作業しないでください。**
> これから入る `node_modules` は数万ファイル・1GB近くになります。
> OneDrive が同期しようとして「ファイルが使用中」エラーや同期の遅延を起こします。
> `C:\dev\WellnessID` のような場所に移してから実行してください。

> 💡 なぜスクリプトなのか：使うライブラリのバージョンは、手で書くと必ずズレます。
> `expo install` というコマンドに「今のExpoに合うバージョン」を選ばせるほうが確実なので、
> それを順番に実行するだけのスクリプトにしています。

### ② ちゃんと入ったか確認

```bash
npm run typecheck    # 型のチェック。何も出なければ成功
npm run lint         # 書き方のチェック
```

### ③ データベースを手元で動かす

```bash
npm run emu
```

ブラウザで `http://localhost:4000` が開けば成功です。
これは**本物そっくりの練習用データベース**で、いくら壊しても本番に影響しません。
止めるときはターミナルで `Ctrl + C`。

### ステップ8が山場です

```
悩みを選ぶ → ランキングが出る → 詳細を見る → 口コミを書く
→ 平均点が更新される → 「近い人」の表示が切り替わる
```

この一本道が動けば、あとの画面はほぼ同じ作りの繰り返しです。
**逆にここが10/20までに動かないなら、機能を削る判断をします。**

## 6. 型を確定させる前に決めること（9/30まで）

この2つが決まるまで、`app/src/types/` は固定しないでください。
あとから変えると、データを全部入れ直すことになります。

| 記号 | 決めること | なぜ急ぐか |
|---|---|---|
| **TODO-A** | 退会した人の口コミを残すか、消すか | 消すと、退会のたびにランキングの人数が変わってしまう |
| **TODO-B** | 口コミの種類（普通／依頼／キャンペーン）の扱いと画面表示 | 最初に仕込む200〜300件は全部「依頼」。あとから付けられない |

どちらも `app/src/types/review.ts` にコメントで印を付けてあります。
