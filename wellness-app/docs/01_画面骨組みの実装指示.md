## 各画面の中身

**`ScreenPlaceholder` を1つ置くだけでよい。**

```tsx
<ScreenPlaceholder
  title="悩み別ランキング"
  screenNo={7}
  note="選んだ悩みに紐づく商品・店舗・専門家を横断で並べる"
/>
```

`ScreenPlaceholder` は次を満たすこと：

- 背景 `colors.bg`、文字 `colors.ink`、補助文字 `colors.inkMuted` を `src/theme/tokens.ts` から取る
- 画面番号・画面名・一行メモを表示する
- `SafeAreaView` を使う
- 動的ルート（`[id]`）では `useLocalSearchParams()` で受け取った id も表示する

## ルートレイアウト（`app/app/_layout.tsx`）

1. `import '../global.css'`（NativeWind v4 に必要）
2. `expo-google-fonts` で Jost と Zen Kaku Gothic New を読み込み、読込中は `null` を返す
   - `Jost_400Regular` / `Jost_600SemiBold`
   - `ZenKakuGothicNew_400Regular` / `_500Medium` / `_700Bold`
3. `QueryClientProvider`（TanStack Query）で全体を包む。`QueryClient` はモジュールスコープで1つ作る
4. `SafeAreaProvider` で包む
5. `Stack` を返す。ヘッダーの背景・文字色は `tokens.ts` から
6. **ダークテーマは実装しない。** `colors`（= community）固定

## タブレイアウト（`app/app/(tabs)/_layout.tsx`）

| ルート | ラベル |
|---|---|
| `index` | ホーム |
| `search` | 探す |
| `ranking` | ランキング |
| `reviews` | 口コミ |
| `mywellness` | MY WELLNESS |

- アクティブ色 `colors.primary`、非アクティブ `colors.inkMuted`、背景 `colors.surface`、上罫線 `colors.line`
- アイコンは `@expo/vector-icons` の `Ionicons` でよい（追加インストールは不要）
- **ロールによる出し分けはしない**（Rev.3 でタブの行き先は固定）

## やってはいけないこと

`CLAUDE.md` §3 の禁止事項に従う。特にこの作業で関係するもの：

- 色のハードコード（`#RRGGBB` を書かない。ESLint が弾く）
- ダークテーマの使用・テーマ切替の実装
- `member/` 配下の作成
- 画面から Firestore を直接呼ぶこと（この段階ではそもそも呼ばない）

## 進め方

1. まず**作成するファイル一覧**を提示して確認を取る
2. 承認後、`ScreenPlaceholder` → `_layout.tsx` → タブ → 個別画面 の順に作る
3. 各ステップで `npm run typecheck` と `npm run lint` を実行し、エラーをゼロにしてから次へ進む
4. 最後に `npx expo start` が起動することを確認する
